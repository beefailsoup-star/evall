# evall

簡單、輕量的 JavaScript 數學運算函式。

支援四則運算、括號、次方、商餘數運算，以及常見科學計算函數。

## 功能

### 基本運算

- 加法 `+`
- 減法 `-`
- 乘法 `*`
- 除法 `/`
- 括號 `()`

```js
evall("(5+3)*2")
```

結果：

```js
16
```

---

#*# 次方運算

使用 `^` 表示次方。

```js
evall(**^10")
```

結果：

```js
1024
```

--*

### 商*數運算

使用 `^^^`。

```js
evall*"13^^^5")
```

結果：

```js
[2, 3]
`*`

表示：

```text
13*÷ 5 = 2 餘 3
```
