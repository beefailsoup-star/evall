# evall

簡單、輕量的 JavaScript 數學運算函式庫。

支援四則運算、括號、次方、商餘數運算，以及常見的科學計算函數。

## 功能特色

- 基本四則運算與括號
- 次方運算
- 商與餘數運算
- 三角函數（角度制）
- 開根號
- 常用對數與自然對數
- 數學常數 `PI` 與 `E`
- 支援巢狀運算與函數呼叫
- 基本運算式安全檢查

## 基本運算

支援以下運算子：

- 加法：`+`
- 減法：`-`
- 乘法：`*`
- 除法：`/`
- 括號：`(`、`)`

範例：

```js
evall("(5+3)*2");
```

結果：

```js
16
```

## 次方運算

使用 `^` 表示次方。

範例：

```js
evall("2^10");
```

結果：

```js
1024
```

## 商與餘數運算

使用 `^^^` 執行商與餘數運算。

範例：

```js
evall("13^^^5");
```

結果：

```js
[2, 3]
```

表示：

```text
13 ÷ 5 = 2 餘 3
```

回傳陣列的第一個元素是商，第二個元素是餘數。

## 三角函數

支援角度制的三角函數：

- `sin(x)`：正弦
- `cos(x)`：餘弦
- `tan(x)`：正切

範例：

```js
evall("sin(30)");
```

結果：

```js
0.5
```

```js
evall("cos(60)");
```

結果：

```js
0.5
```

```js
evall("tan(45)");
```

結果：

```js
1
```

注意：三角函數的輸入角度以度數（Degrees）計算，而不是弧度（Radians）。

## 開根號

使用 `sqrt(x)` 計算平方根。

範例：

```js
evall("sqrt(2025)");
```

結果：

```js
45
```

## 對數

### 常用對數

使用 `log(x)` 計算以 10 為底的對數。

範例：

```js
evall("log(1000)");
```

結果：

```js
3
```

### 自然對數

使用 `ln(x)` 計算以自然常數 `e` 為底的對數。

範例：

```js
evall("ln(E)");
```

結果：

```js
1
```

## 數學常數

### 圓周率 π

使用 `PI` 表示圓周率。

```js
evall("PI");
```

結果約為：

```js
3.141592653589793
```

### 自然常數 e

使用 `E` 表示自然常數。

```js
evall("E");
```

結果約為：

```js
2.718281828459045
```

## 巢狀運算

支援在運算式中組合括號、運算子與函數呼叫。

範例：

```js
evall("sin(cos(60)*30)");
```

此範例先計算 `cos(60)`，再將結果乘以 30，最後計算正弦值。

另一個範例：

```js
evall("sqrt((10+5)^2)");
```

結果：

```js
15
```

## 安全機制

evall 預期提供以下安全檢查：

- **字元白名單**：限制可接受的運算式字元。
- **括號匹配檢查**：檢查括號是否正確配對。
- **Infinity 過濾**：偵測無限大結果。
- **NaN 過濾**：偵測無效數值結果。
- **未知函數阻擋**：拒絕未支援的函數名稱。
- **除以零檢查**：避免除數為零的運算。

實際的錯誤處理方式（例如回傳 `null`、回傳錯誤物件或拋出例外），請以實際實作為準。

## 使用方式

### 1. 引入 JavaScript 檔案

將 `evall.js` 放在 HTML 檔案可存取的位置。

```html
<script src="evall.js"></script>
```

### 2. 執行數學運算

```html
<script src="evall.js"></script>

<script>
  const result = evall("5*(3+2)");
  console.log(result);
</script>
```

預期輸出：

```text
25
```

## 注意事項

- 本函式庫使用的運算子、函數名稱及回傳格式，應與實際的 `evall.js` 實作一致。
- 次方與商餘數運算的優先順序，應由實作明確定義。
- `tan(x)` 在某些角度可能無法產生有限的數值。
- 對數的輸入必須符合數學定義域。
- 不應將本函式庫視為完整的 JavaScript 沙箱；若要處理不可信任的使用者輸入，仍應確認解析器的實作方式。
